## 🚀 The 3-Step Setup

### Step 1: Update GitHub Username (30 seconds)
Replace `YOUR_GITHUB_USERNAME` in:
- `app/utils/github.ts` (line 5)
- `app/Components/GitHubProjects.tsx` (line 22)

### Step 2: Update Social Links (1 minute)
Edit `app/JsonData/social.json` with your:
- GitHub URL
- LinkedIn URL
- Email
- Phone

### Step 3: Test or Deploy (5 minutes)
**Test locally:**
```bash
npm run dev
# Visit http://localhost:3000
```

**Deploy:**
```bash
git push
# Deploy on vercel.com
```

## 🆘 Need Help?

### GitHub projects not showing?
1. Check username spelling (case matters!)
2. Verify you have public repos
3. Clear browser cache (Ctrl+Shift+Delete)
4. Hard refresh page (Ctrl+Shift+R)

### Getting errors?
1. Run `npm install`
2. Run `npm run dev` again
3. Check console for specific error (F12)

### Want to customize colors?
Edit `app/globals.css`:
```css
--prim-color: #your-color;
```
